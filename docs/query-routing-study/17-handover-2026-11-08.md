  were plain surveys. Opening fetched more text, but the agent took it as a reason to stop sooner.

- **Run admin consoles from Obsidian** (the artmind plugin starts `artmind admin-ui` in the vault). Both vaults'
  `.artmind/config.env` set `ARTMIND_PLAN_SHADOW_RUN=1` and `ARTMIND_AGENT_CONTRACT=classic` (gitignored). The
  benchmark form picks each run's contract.
- **After code changes:** stop the consoles, fast-forward `~/projects/artmind9`, then restart. A skill-only change
  needs no restart: vault skills are symlinks into the main checkout and are read fresh per question. **Fast-forward
  the main checkout before the user starts runs**; one run was wasted on 2026-11-08 because this was not done.
- **`just dev-install`** stops only the daemon on port 8379. Kill any other admin-ui (`pgrep -fl 'artmind admin-ui'`).
- **Judge calls** go through `ARTMIND_KG_LLM_PROVIDER` (ibm_ica). Sonnet 5.5 does not accept temperature 0, so
  verdicts are not pinned; they are cached in `trace_judgements`.
- **From a Claude Code shell,** strip `ANTHROPIC_BASE_URL`, `CLAUDECODE` and `CLAUDE_CODE_ENTRYPOINT`
  (CLAUDE.md §5).
- **Classic B replay trap:** two classic runs close together can come back byte-identical (gateway replay). Space them
  apart, and check `A == B` answer identity before trusting the band.
