## Setting up laptop B

```bash
git -C <checkout> pull
just dev-install
just dev-stop-daemons
```

Then pull each vault's private repo and start `serve` again from inside the vault.

- **Gateway trap (CLAUDE.md §5).** A Claude Code shell exports its own
  `ANTHROPIC_BASE_URL`; any `artmind` LLM call (ingest, summarise, topic build) run from it
  goes to the gateway and fails with 404. Set `ARTMIND_KG_ANTHROPIC_BASE_URL` in
  `~/.artmind/config.env`, or prefix a command with `env -u ANTHROPIC_BASE_URL`.
- **Harness facts are version- and gateway-dependent.** Lessons §2.1 records Claude Code's
  Bash output limits as measured on the desktop on 2026-11-04. Re-check them on laptop B
  before the design relies on a number.
- Use `ARTMIND_NO_PROXY=1` for every query you run to test or probe.
