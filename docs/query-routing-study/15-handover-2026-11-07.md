## Decisions taken with the user (do not reopen without evidence)

1. **The agent decides whether a turn needs a lookup**, not the planner (architecture §5.5, 4a). It
   handles reshapes, deliverables (tables, files), curation hand-offs, status and ops itself and calls
   the planner only for lookups, follow-ups included. Non-retrieval intents are a safety net.
2. **Gate**: no wrong view, under 10 % wrong, no flips, no non-retrieval label planned as a confident
   lookup. A lexical pass made of abstentions is hollow: report the correct-at-high share beside it.
3. **`procedure` is removed** (folded into `search`; B2). `search` and `survey` graded as one.
4. **Families of domains** (`X`, `X.a`): text routes search the family root; entity and document routes
   scope to where the subject lives; structured to the domains holding the tables (B2 §6).
5. **Two chunks-only domains, none named → search both** (nbs_audit_2026; B1 `chunks_only_all`).
6. **No LLM classifier for now.** If tried, only as a fallback for low-confidence threaded turns,
   compared by replay.
7. **`episode`** is the route name for span questions (not `event`: `EVENT` is a schema class); it waits
   for the assembly pass and P3's step bindings.

```bash

```

Then pull the vaults (`~/artmind_vaults/{brain01,nbs_audit_2026,banking_corpus}`; Obsidian Git
commits them) and copy `~/artmind-private/` by hand if this is a new machine.

Traps:
1. **The inference gateway.** Claude Code exports its own `ANTHROPIC_BASE_URL` (and `CLAUDECODE`,
   `CLAUDE_CODE_ENTRYPOINT`) into every shell it runs. artmind does not override real environment
   variables, so an artmind LLM call from that shell goes to the gateway and fails (404) unless
   `ARTMIND_KG_ANTHROPIC_BASE_URL` is set in `~/.artmind/config.env` (CLAUDE.md §5). Check with
   `env | grep ^ANTHROPIC_`. Start daemons with the gateway variables removed, from inside the vault:

   ```bash
   cd ~/artmind_vaults/banking_corpus && env -u ANTHROPIC_BASE_URL -u CLAUDECODE -u CLAUDE_CODE_ENTRYPOINT ARTMIND_SERVE_PORT=8393 artmind serve
   ```

   ```bash
   cd ~/artmind_vaults/banking_corpus && env -u ANTHROPIC_BASE_URL -u CLAUDECODE -u CLAUDE_CODE_ENTRYPOINT ARTMIND_SERVE_PORT=8393 artmind admin-ui --host 127.0.0.1 --port 8382
   ```

   The admin UI's own agent (Claude SDK) then uses the credentials in `~/.artmind/config.env`, not the
   gateway of the Claude Code session that started it.
2. **The decision model** runs on OpenRouter: `~/.artmind/config.env` needs
   `ARTMIND_DECISION_PROVIDER=openrouter`, `ARTMIND_DECISION_MODEL` (`typesafe/jev-1.14`),
   `ARTMIND_OPENROUTER_API_KEY` and `ARTMIND_DECISION_TIMEOUT`. Without them replay's decision runs fall
   back to lexical (`fell_back` > 0 in the report). It sends planned questions off the machine; the
   user has agreed to that for all three vaults.
3. **Model names** for sub-agents may differ on another gateway: use whatever it names the current
   Sonnet and Haiku.
4. A running `serve` or UI serves the code it started with; restart after every merge. Plans with
   `--previous` never go through `serve`.
