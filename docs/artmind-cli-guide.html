artmind
CLI Reference Guide

Artmind — A Knowledge System That Synchronizes with Your Mind

Artmind is a CLI tool for building, querying, and maintaining a knowledge graph backed by Neo4j and SQLite. It ingests documents, extracts entities and relationships via LLMs, and provides rich graph + vector queries.

Usage: artmind [OPTIONS] COMMAND [ARGS]...
1
Initialize
artmind setup
2
Add Domain Schema
artmind domains add schema.yaml
3
Ingest Documents
artmind ingest sync ./docs/
4
Query
artmind query vector-text "question" -d mydomain
⚙

artmind ingest refine-graph Find similar entity names, merge aliases into canonical entities ▶
Workflow:
1. Dry-run: artmind ingest refine-graph --dry-run --output merges.json
2. Review merges.json and edit if needed
3. Execute: artmind ingest refine-graph --from-file merges.json
Usage: artmind ingest refine-graph [OPTIONS]
Options
--domainTEXTRestrict to entities in this domain (default: all)
--filterTEXTFilter entities by name (comma-separated for multiple)
--modelTEXTLLM model for merge decisions
--thresholdFLOATString similarity threshold (0–1) [default: 0.7]
--dry-runFLAGCompute proposals only; do NOT apply
--outputPATHWrite proposals JSON (default: data/refine/proposed_merges.json)
--from-filePATHSkip computation — load and apply from prior dry-run
--allow-cross-domain-mergeFLAGAllow merging same-named entities across domains
artmind ingest refine-pipeline Run all refinement steps in dependency order --domain required ▶
Runs: time → supersession → merge → conflicts → consolidate → embed

Workflow:
1. Propose: artmind ingest refine-pipeline --domain <d>
2. Review the report and its merges_*.json / conflicts_*.json
3. Apply: artmind ingest refine-pipeline --domain <d> --from-file <report>

Use --apply to skip the review gate (trusted automation only).
Usage: artmind ingest refine-pipeline [OPTIONS]
Options
--domainTEXTDomain to refine (repeatable; 2+ adds cross-domain conflicts pass)required
--applyFLAGOne-shot: compute AND apply every step (skips review gate)
--from-filePATHApply vetted proposals from a prior report
--stepsTEXTComma-separated subset of: time,supersession,merge,conflicts,consolidate,embed
--modelTEXTLLM model for merge/conflict/consolidation calls
--mergeThresholdFLOATSimilarity threshold for merge clustering [default: 0.7]
--simThresholdFLOATSimilarity threshold for conflict candidate pairs [default: 0.75]
--maxPairsINTEGERCap on conflict candidate pairs [default: 200]
--sampleConsolidationsINTEGERConsolidation samples per domain in propose mode [default: 3]
--consolidateLimitINTEGERCap entities consolidated per domain in apply mode
--compactFLAGEmit compact JSON

Sessions
Save and restore the Neo4j graph between sessions
▼
artmind session close Export the full Neo4j graph to a compressed snapshot (end of session) ▶
Creates a compressed .tar.gz snapshot of the entire Neo4j graph. Use at end of session to preserve state.
Usage: artmind session close [OPTIONS]
artmind session initiate Wipe Neo4j and restore from a snapshot (start of session) ▶
Restores the graph from a snapshot. By default uses the latest in data/graph_snapshot/. Use --yes to skip the confirmation prompt.
Usage: artmind session initiate [OPTIONS]
Options
--snapshotPATHPath to a specific snapshot .tar.gz (default: latest in data/graph_snapshot/)
--yesFLAGSkip confirmation prompt

# Restore from a specific snapshot, skip confirmation
