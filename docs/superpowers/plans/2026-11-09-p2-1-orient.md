# P2-1 `artmind query orient` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `artmind query orient` (peel 1: corpus + one card per domain) and `artmind query orient --domain d[,d2]` (peel 2: classes with definitions and measured types, relation shapes, stores, views, assets, documents with successors) give the query agent a layered, question-free description of the corpus; a skill variant `artmind-query-orient` replaces ~120 lines of orientation text with ~25.

**Architecture:** Facts come from three sources: the domain schema files (purpose, class definitions, `kind`, the dating rule), the per-domain narrator file (`domains/plan/<domain>.yaml`, read by a new planner-free `artmind/domain_config.py`), and the catalogue cache (`artmind/catalogue/`), which gains three graph parts (`shapes`, `types`, `versions`) and a content-dated `time`. A new package `artmind/orient/` assembles cards (`card.py`), domain blocks (`domain.py`) and fits them to a budget (`budget.py`); `cli.py` adds one command. No question input, no routing, no LLM call, no planner import.

**Tech Stack:** Python 3.14, Click, Neo4j (read-only Cypher through `graph_query._run_read_query`), PyYAML, pytest with `CliRunner` and recorded fake graphs.

**Spec:** `docs/superpowers/specs/2026-11-09-p2-1-orient-design.md` (this plan's §-references point there). Parent: `docs/superpowers/specs/2026-11-08-classic-baseline-and-skill-simplification-design.md` §4.2, §3.4.

## Deviations from the spec, decided here

1. **`stores.structured` in peel 2 lists tables, grain, row count and bridge classes** from `structured.registry.routing_surface`, not the whole `db bridge` row (statuses and column lists stay in `db bridge`; `cuts.rest` names it).
2. **Relation shapes are a new catalogue part `shapes`**, not a change to `relations`: the planner reads `relations` as `(rel_type, count)` pairs (`query_plan/candidates.py`), and the planner is frozen.
3. **`time` changes in place**: it gains `from_content`, `content_earliest`, `content_latest`; its existing keys keep their meaning (`with_valid_from` still counts every dated document). `CATALOGUE_FORMAT` 3 → 4.
4. **Budgets and cut order revised after a live run** (user decision, 2026-11-09): definitions are cut last; peel 1 9,000, peel 2 12,000 per domain, 24,000 per call (Task 6). The spec §5.1 is updated in the same commit as this plan.
5. **Catalogue parts roll up dotted children** (`domain_predicate` matches `d` and `d.*`). So a family root's card describes the whole family and carries `rolls_up: <child count>`; corpus totals sum only cards with no ancestor card (no double counting); and peel 2 `--domain <root>` opens the root's children, not a rolled-up root block (structured tables are not lost: `list_tables` includes ancestors' tables under each child).
6. **Family collapse in peel 1** happens only over budget, and collapses whole families, largest first (§5.1). Banking (9 domains) and brain01 (1) must not collapse at the default budget — a live check in Task 10 confirms it.

```python
"""Per-domain config read outside the frozen planner (spec 2026-11-09 §5.3).

`<ARTMIND_HOME>/domains/plan/<domain>.yaml` is user data (never seeded). A parent
domain's file applies to a child without one (most specific wins, never merged).
This module reads only what the classic CLI needs: the domain-name rule and the
narrator. The planner keeps its own full parser in `query_plan/config.py`.
"""
from __future__ import annotations

import re
from pathlib import Path

import yaml

_DOMAIN_RE = re.compile(r"[A-Za-z0-9_][A-Za-z0-9_-]*(\.[A-Za-z0-9_][A-Za-z0-9_-]*)*")
_CLASS_RE = re.compile(r"[A-Z_][A-Z0-9_]*")


class DomainConfigError(ValueError):
    """A per-domain config file cannot be read or breaks the narrator shape."""


def is_domain_name(name) -> bool:
    """True for a dotted domain name whose whole string matches (no trailing newline, no path parts)."""
    return isinstance(name, str) and _DOMAIN_RE.fullmatch(name) is not None


def config_dir() -> Path:
    import paths

    return Path(paths.DOMAIN_PLAN_DIR)


def config_file(domain: str) -> Path | None:
    """The most specific file for `domain`: its own, else its nearest parent's."""
    if not is_domain_name(domain):
        return None
    parts = domain.split(".")
    for i in range(len(parts), 0, -1):
        path = config_dir() / f"{'.'.join(parts[:i])}.yaml"
        if path.is_file():
            return path
    return None


def _class_name(raw: str, source: str) -> str:
    name = re.sub(r"[^A-Za-z0-9_]", "_", raw.strip()).upper()
    if not _CLASS_RE.fullmatch(name) or not re.search(r"[A-Z]", name):
        raise DomainConfigError(f"{source}: narrator entity_class {raw!r} is not a usable class name")
    return name


def narrator(domain: str) -> dict | None:
    """`{entity_class, name, aliases}` from the domain's config file, or None when no file or no
    narrator is configured. Raises DomainConfigError for an unreadable file or a malformed narrator."""
    path = config_file(domain)
    if path is None:
        return None
    try:
        data = yaml.safe_load(path.read_text(encoding="utf-8")) or {}
    except (OSError, UnicodeDecodeError, yaml.YAMLError) as exc:
        raise DomainConfigError(f"{path} cannot be read: {exc}") from exc
    raw = data.get("narrator") if isinstance(data, dict) else None
    if raw is None:
        return None
    if (not isinstance(raw, dict) or not {"entity_class", "name"} <= set(raw)
            or not all(isinstance(raw[k], str) and raw[k].strip() for k in ("entity_class", "name"))):
        raise DomainConfigError(f"{path}: narrator must be {{entity_class, name, aliases?}}")
    aliases = raw.get("aliases") or []
    if not isinstance(aliases, list) or not all(isinstance(a, str) for a in aliases):
        raise DomainConfigError(f"{path}: narrator aliases must be a list of strings")
    return {"entity_class": _class_name(raw["entity_class"], str(path)), "name": raw["name"].strip(),
            "aliases": list(dict.fromkeys(a.strip() for a in aliases if a.strip()))}
```

```python
_TIME_CYPHER = f"""
MATCH (d:Document)
WHERE {domain_predicate("d")}
WITH d, coalesce(d._valid_time_source, '') <> 'default_ingestion' AND d._valid_from IS NOT NULL AS from_content
RETURN count(d) AS documents, count(d._valid_from) AS with_valid_from,
       min(d._valid_from) AS earliest, max(d._valid_from) AS latest,
       count(CASE WHEN from_content THEN 1 END) AS from_content,
       min(CASE WHEN from_content THEN d._valid_from END) AS content_earliest,
       max(CASE WHEN from_content THEN d._valid_from END) AS content_latest
"""

_SHAPES_CYPHER = f"""
MATCH (a:Entity)-[r:RELATES_TO]->(b:Entity)
WHERE {domain_predicate("a")} AND r.rel_type IS NOT NULL
  AND a.entity_class IS NOT NULL AND b.entity_class IS NOT NULL
RETURN a.entity_class AS src, r.rel_type AS rel, b.entity_class AS dst, count(r) AS n
ORDER BY n DESC, rel, src, dst
LIMIT $limit
"""

_TYPES_CYPHER = f"""
MATCH (e:Entity)
WHERE {domain_predicate("e")} AND e.entity_class IS NOT NULL
WITH e.entity_class AS cls,
     CASE WHEN e.type IS NULL THEN null ELSE toLower(trim(toString(e.type))) END AS t,
     coalesce(e._valid_time_source = 'property', false) AS dated
WITH cls, t, count(*) AS n, sum(CASE WHEN dated THEN 1 ELSE 0 END) AS d
RETURN cls, collect({{type: t, n: n}}) AS types, sum(n) AS total, sum(d) AS dated
"""

_VERSIONS_CYPHER = f"""
CALL () {{
  MATCH (d:Document) WHERE {domain_predicate("d")}
  RETURN d.name AS name, 'current' AS status, d._valid_from AS valid_from,
         d.superseded_by AS successor_id, COUNT {{ (d)-[:SUPERSEDES]->() }} AS replaces
  UNION ALL
  MATCH (d:DocumentHistory) WHERE {domain_predicate("d")}
  RETURN d.name AS name, 'retired' AS status, d._valid_from AS valid_from,
         d.superseded_by AS successor_id, 0 AS replaces
}}
WITH * WHERE status = 'retired' OR successor_id IS NOT NULL OR replaces > 0
OPTIONAL MATCH (s:Document|DocumentHistory {{id: successor_id}})
RETURN name, status, valid_from, s.name AS successor, replaces
ORDER BY name, status
"""
```

```python
def build_time(domain: str) -> dict:
    rows = _run(_TIME_CYPHER, {"domains": [domain]})
    row = rows[0] if rows else {}
    total = int(row.get("documents") or 0)
    dated = int(row.get("with_valid_from") or 0)

    def day(v):
        return None if v is None else str(v)

    return {"time": {
        "documents": total, "with_valid_from": dated,
        "share": round(dated / total, 4) if total else 0.0,
        "earliest": day(row.get("earliest")), "latest": day(row.get("latest")),
        "from_content": int(row.get("from_content") or 0),
        "content_earliest": day(row.get("content_earliest")), "content_latest": day(row.get("content_latest")),
    }}


def build_shapes(domain: str) -> dict:
    return {"shapes": tuple(
        (r["src"], r["rel"], r["dst"], int(r["n"]))
        for r in _run(_SHAPES_CYPHER, {"domains": [domain], "limit": SHAPES_MAX})
    )}


def build_types(domain: str) -> dict:
    """Per class: entity total, how many carry their own date, and the `type` values held by at
    least TYPE_MIN_ENTITIES entities (top TYPES_TOP); `distinct` counts every non-null value."""
    out = []
    for r in _run(_TYPES_CYPHER, {"domains": [domain]}):
        values = sorted(((str(t["type"]), int(t["n"])) for t in r["types"] if t.get("type")),
                        key=lambda tv: (-tv[1], tv[0]))
        top = [[t, n] for t, n in values if n >= TYPE_MIN_ENTITIES][:TYPES_TOP]
        out.append((str(r["cls"]), {"total": int(r["total"]), "distinct": len(values),
                                    "dated": int(r["dated"]), "top": top}))
    return {"types": tuple(sorted(out, key=lambda cv: (-cv[1]["total"], cv[0])))}


def build_versions(domain: str) -> dict:
    """Retired documents and the live documents that replaced one: name, status, date, successor."""
    out = []
    for r in _run(_VERSIONS_CYPHER, {"domains": [domain]}):
        rec = {"name": r["name"], "status": r["status"],
               "valid_from": None if r.get("valid_from") is None else str(r["valid_from"]),
```

```python
"""Facts a domain's schema file declares about itself (spec 2026-11-09 §3, §4.1). No graph access.

`read(domain)` returns None when the domain has no schema here, and raises SchemaFactsError when
the file exists but cannot be parsed, so the caller can name the part in `warnings`.
"""
from __future__ import annotations

import re

PURPOSE_MAX = 200
_SENTENCE_END = re.compile(r"(?<=[.!?])\s+")


class SchemaFactsError(ValueError):
    pass


def _squash(text) -> str:
    return " ".join(str(text or "").split())


def _purpose(description: str) -> str | None:
    text = _squash(description)
    if not text:
        return None
    if len(text) <= PURPOSE_MAX:
        return text
    out = ""
    for sentence in _SENTENCE_END.split(text):
        candidate = f"{out} {sentence}".strip()
        if len(candidate) > PURPOSE_MAX:
            break
        out = candidate
    return out or text[:PURPOSE_MAX].rsplit(" ", 1)[0]


def _first_field(names) -> str | None:
    names = names if isinstance(names, list) else [names]
    return next((str(n) for n in names if n), None)


def _filename_pattern(temporal: dict) -> str | None:
    for rule in ((temporal.get("document_patterns") or {}).get("valid_from") or []):
        if isinstance(rule, dict) and rule.get("filename"):
            return str(rule["filename"])
    return None


def _time_rule(temporal: dict) -> dict:
    document = temporal.get("document") or {}
    rule: dict = {}
    for key in ("valid_from", "version"):
        field = _first_field(document.get(key))
        parts = [f"document field '{field}'"] if field else []
        if key == "valid_from" and (pattern := _filename_pattern(temporal)):
            parts.append(f"filename {pattern}")
        if parts:
            rule[key] = ", or ".join(parts)
    return rule


def read(domain: str) -> dict | None:
    from artmind import temporal

    try:
        schema = temporal.load_schema(domain)
    except Exception as exc:  # a YAML error or unreadable file
        raise SchemaFactsError(f"{domain}: schema unreadable: {exc}") from exc
    if not schema:
        return None
    if not isinstance(schema, dict):
        raise SchemaFactsError(f"{domain}: schema is not a mapping")
    temporal_block = schema.get("temporal") or {}
    classes = {}
    for name, spec in (schema.get("entity_types") or {}).items():
        spec = spec or {}
        classes[str(name)] = {"kind": spec.get("kind"), "definition": _squash(spec.get("description")) or None}
    return {
        "purpose": _purpose(schema.get("description")),
        "time_rule": _time_rule(temporal_block),
        "filename_pattern": _filename_pattern(temporal_block),
        "classes": classes,
    }
```

```python
"""Peel 1 (spec 2026-11-09 §2.2, §3): one card per domain, the family tree and the corpus block.

Pure: takes a loaded `DomainCatalogue`, the schema facts and the narrator, returns dicts.
A part the catalogue did not load is left out of the card and named in `warnings`; `null`
always means "declared absent" (no narrator, no filename rule, no insights snapshot).
"""
from __future__ import annotations

VOCABULARY = 5
_COVERAGE = ("behind_vault", "summaries_missing")


def family_tree(domains) -> dict:
    """{root: [children]} over every domain name; a root with no children maps to []."""
    names = sorted(set(domains))
    tree: dict = {}
    for d in names:
        root = d.split(".", 1)[0]
        tree.setdefault(root, [])
        if d != root:
            tree[root].append(d)
    return tree


def family_of(domain: str, tree: dict) -> tuple:
    """(family root, sibling count) for a dotted child; (None, 0) for a root."""
    root = domain.split(".", 1)[0]
    if domain == root:
        return None, 0
    return root, max(0, len(tree.get(root, [])) - 1)


def _summaries(records) -> str:
    total = len(records)
    have = sum(1 for r in records if r.has_summary)
    if not total or have == total:
        return "all" if total else "none"
    return "none" if have == 0 else f"{have} of {total}"


def _insights_as_of(assets) -> str | None:
    dates = [str(a.get("detail", {}).get("as_of")) for a in assets
             if a.get("kind") == "insight" and a.get("detail", {}).get("as_of")]
    return max(dates) if dates else None


def _stores(stores: dict) -> list:
    out = ["graph" if stores.get("graph_extraction", True) else "chunks"]
    if stores.get("structured_tables"):
        out.append("structured")
    return out


def _missing(warnings, domain: str, part: str) -> None:
    if warnings is not None:
        warnings.append(f"{domain}: {part} not read")


def build_card(cat, facts: dict | None, narrator: dict | None, family: tuple, *, children: int = 0,
               warnings: list | None = None) -> dict:
    d = cat.domain
    root, siblings = family
    c: dict = {"domain": d, "family": root, "siblings": siblings}
    if children:
        c["rolls_up"] = children  # catalogue parts include the dotted children
    if facts is None:
        if warnings is not None:
            warnings.append(f"{d}: schema not found; purpose, dating rule and class definitions unknown")
    elif facts.get("purpose"):
        c["purpose"] = facts["purpose"]
    if cat.has("stores") and cat.stores is not None:
        c["kind"] = "graph" if cat.stores.get("graph_extraction", True) else "chunks-only"
        c["stores"] = _stores(cat.stores)
    else:
        _missing(warnings, d, "stores")
    if cat.has("documents"):
        records = sorted(cat.doc_records, key=lambda r: r.name)
        c["unit"] = {"documents": len(records), "pattern": (facts or {}).get("filename_pattern"),
                     "example": records[0].name if records else None}
    else:
        _missing(warnings, d, "documents")
    c["voice"] = (None if narrator is None else
                  {"narrator": narrator["name"], "entity_class": narrator["entity_class"], "first_person": True})
    if cat.has("time") and cat.time is not None:
        t = cat.time
        time_block = {
            "rule": (facts or {}).get("time_rule") or {},
            "dated": {"from_content": int(t.get("from_content", 0)),
                      "defaulted_to_ingestion": int(t.get("documents", 0)) - int(t.get("from_content", 0))},
            "span": ([t["content_earliest"], t["content_latest"]] if t.get("content_earliest") else None),
        }
        if cat.has("versions"):
            time_block["versions"] = {"with_successor": sum(1 for v in cat.versions if v.get("replaces")),
                                      "retired": sum(1 for v in cat.versions if v["status"] == "retired")}
        else:
            _missing(warnings, d, "versions")
        c["time"] = time_block
    else:
        _missing(warnings, d, "time")
    if cat.has("classes"):
        c["vocabulary"] = [name for name, _, _ in cat.classes[:VOCABULARY]]
    else:
        _missing(warnings, d, "classes")
    if len(cat.fingerprint) > 1:
        c["entities"] = int(cat.fingerprint[1])
    if cat.has("assets") and cat.assets is not None:
        kinds = [a.get("kind") for a in cat.assets]
        c["assets"] = {"views": kinds.count("view"), "topic_pages": kinds.count("topic"),
                       "insights": _insights_as_of(cat.assets),
                       "summaries": _summaries(cat.doc_records) if cat.has("documents") else None}
    else:
        _missing(warnings, d, "assets")
    if cat.has("health") and cat.health:
        coverage = {k: int((cat.health.get(k) or {}).get("count") or 0) for k in _COVERAGE}
        coverage = {k: v for k, v in coverage.items() if v > 0}
        if coverage:
            c["coverage"] = coverage
    return c


def corpus_block(cards: list, tree: dict, *, generation: int, built_at: str) -> dict:
    """Totals over the top cards only: a card whose ancestor also has a card is already inside it."""
    names = {c["domain"] for c in cards}
    top = [c for c in cards if not any(c["domain"].startswith(n + ".") for n in names)]
    spans = [c["time"]["span"] for c in top if (c.get("time") or {}).get("span")]
    return {
        "domains": len(cards),
        "families": tree,
        "documents": sum((c.get("unit") or {}).get("documents", 0) for c in top),
        "entities": sum(c.get("entities", 0) for c in top),
        "span": [min(s[0] for s in spans), max(s[1] for s in spans)] if spans else None,
        "generation": generation,
        "built_at": built_at,
    }
```

```python
"""Peel 2 (spec 2026-11-09 §4, §4.1): what a domain holds and what already answers.

Pure over a loaded `DomainCatalogue` and schema facts, plus two file/registry reads (saved
views, structured tables). A part that was not read or failed is absent and named in `warnings`.
"""
from __future__ import annotations

from loguru import logger

VIEW_EXAMPLES = 2


def _classes(cat, facts: dict | None) -> list:
    declared = (facts or {}).get("classes") or {}
    types = dict(cat.types) if cat.has("types") else None
    out = []
    for name, count, _ in cat.classes:
        spec = declared.get(name) or {}
        row = {"class": name, "count": count, "kind": spec.get("kind"), "definition": spec.get("definition")}
        if types is not None:
            t = types.get(name) or {"total": count, "distinct": 0, "dated": 0, "top": []}
            row["types"] = {"top": t["top"], "distinct": t["distinct"]}
            row["dated"] = round(t["dated"] / t["total"], 2) if t["total"] else 0.0
        out.append(row)
    return out


def _views(domain: str, warnings: list):
    from artmind.kg_views import store

    try:
        good, invalid = store.list_views([domain])
    except Exception as exc:
        warnings.append(f"{domain}: views unreadable: {exc}")
        return None
    if invalid:
        warnings.append(f"{domain}: {len(invalid)} invalid view(s) left out (artmind query views list)")
    out = []
    for loaded in good:
        spec = loaded.spec
        out.append({"name": spec.name, "summary": spec.summary,
                    "params": {n: {"type": p.type, "required": p.required,
                                   **({"entity_class": p.entity_class} if p.entity_class else {})}
                               for n, p in spec.params.items()},
                    "examples": list(spec.examples)[:VIEW_EXAMPLES]})
    return out


def _structured(domain: str, warnings: list):
    from artmind.structured import registry

    try:
        rows = registry.routing_surface([domain])
    except Exception as exc:
        logger.debug("orient: routing surface for {} failed: {}", domain, exc)
        warnings.append(f"{domain}: structured tables unreadable: {exc}")
        return None
    return [{"table": r["table"], "grain": r.get("grain"), "rows": r.get("row_count"),
             "bridge_classes": [e["entity_class"] for e in r.get("entity_classes") or []]} for r in rows]


def build_block(cat, facts: dict | None, *, card: dict, warnings: list) -> dict:
    d = cat.domain
    out: dict = {"domain": d, "card": card}
    if cat.has("classes"):
        out["classes"] = _classes(cat, facts)
        if not cat.has("types"):
            warnings.append(f"{d}: types not read")
    else:
        warnings.append(f"{d}: classes not read")
    if cat.has("shapes"):
        out["relations"] = [{"from": s, "rel": r, "to": t, "count": n} for s, r, t, n in cat.shapes]
    else:
        warnings.append(f"{d}: shapes not read")
    if cat.has("stores") and (cat.stores or {}).get("structured_tables"):
        tables = _structured(d, warnings)
        if tables is not None:
            out["structured"] = tables
    views = _views(d, warnings)
    if views is not None:
        out["views"] = views
    if cat.has("assets") and cat.assets is not None:
        out["topics"] = [a.get("title") for a in cat.assets if a.get("kind") == "topic"]
        detectors = sorted(a["id"] for a in cat.assets if a.get("kind") == "insight")
        as_of = max((str(a["detail"]["as_of"]) for a in cat.assets
                     if a.get("kind") == "insight" and a.get("detail", {}).get("as_of")), default=None)
        out["insights"] = {"as_of": as_of, "detectors": detectors} if detectors else None
    else:
        warnings.append(f"{d}: assets not read")
    if cat.has("versions"):
        out["documents"] = [dict(v) for v in cat.versions]
    else:
        warnings.append(f"{d}: versions not read")
    return out
```

```python
"""Orient's own budgets (spec 2026-11-09 §5.1). Every cut is returned in `cuts`; nothing is dropped
silently. Sizes are compact-JSON characters. Class definitions are cut last: they are what peel 2
is for (§4.1)."""
from __future__ import annotations

import copy
import json

CORPUS_BUDGET = 9000
DOMAIN_BUDGET = 12000
CALL_BUDGET = 24000
RELATIONS_KEEP = 20
TYPES_KEEP = 5
DOCUMENTS_KEEP = 10

CUT_ORDER = ["relations", "topics", "types", "view_examples", "documents", "definitions"]


def size(x) -> int:
    return len(json.dumps(x, separators=(",", ":"), ensure_ascii=False, default=str))


def _rest(part: str, d: str) -> str:
    return {
        "relations": f"artmind query graph metadata --domain {d}",
        "topics": f"artmind query topics list --domain {d}",
        "types": f"artmind query graph entity-listing --domain {d} --countAll",
        "view_examples": "artmind query views show <name>",
        "documents": f"artmind query graph structural-metadata --domain {d}",
        "definitions": f"artmind query graph metadata --domain {d}",
    }[part]


def _cut(block: dict, part: str, limit: int) -> dict | None:
    """Apply one cut step to `block` in place; return the cut record or None when it removed nothing."""
    d = block.get("domain")
    classes = block.get("classes") or []
    if part == "types":
        hit = False
        for c in classes:
            top = (c.get("types") or {}).get("top")
            if top and len(top) > TYPES_KEEP:
                c["types"]["top"] = top[:TYPES_KEEP]
                hit = True
        return {"part": part, "domain": d, "shown": TYPES_KEEP, "total": None} if hit else None
    if part == "view_examples":
        views = [v for v in block.get("views") or [] if v.get("examples")]
        for v in views:
            v["examples"] = []
        return {"part": part, "domain": d, "shown": 0, "total": len(views)} if views else None
    if part == "definitions":
        defined = [c for c in classes if c.get("definition")]
        removed = 0
        for c in sorted(defined, key=lambda c: (c["count"], c["class"])):
            if size(block) <= limit:
                break
            c["definition"] = None
            removed += 1
        return {"part": part, "domain": d, "shown": len(defined) - removed, "total": len(defined)} if removed else None
    key, keep = {"relations": ("relations", RELATIONS_KEEP), "topics": ("topics", 0),
                 "documents": ("documents", DOCUMENTS_KEEP)}[part]
    rows = block.get(key)
    if not isinstance(rows, list) or len(rows) <= keep:
        return None
    total = len(rows)
    block[key] = rows[:keep]
    if part == "topics":
        block["topics_total"] = total
    return {"part": part, "domain": d, "shown": keep, "total": total}


def _fit_block(block: dict, limit: int) -> list:
    cuts = []
    for part in CUT_ORDER:
        if size(block) <= limit:
            break
        rec = _cut(block, part, limit)
        if rec:
            rec["rest"] = _rest(part, block.get("domain"))
            cuts.append(rec)
    return cuts


def fit_domains(blocks: list, *, domain_budget: int = DOMAIN_BUDGET, call_budget: int = CALL_BUDGET) -> tuple:
    blocks = copy.deepcopy(blocks)
    cuts: list = []
    for b in blocks:
        cuts += _fit_block(b, domain_budget)
    while size(blocks) > call_budget:
        largest = max(blocks, key=size)
        before = size(largest)
        target = max(1, before - (size(blocks) - call_budget))
        new = _fit_block(largest, target)
        if not new or size(largest) >= before:
            break  # nothing left to cut: the payload stays over budget and `cuts` says what was cut
        cuts += new
    merged: dict = {}
    for c in cuts:  # one record per (domain, part): a later pass on the same part replaces the earlier
        merged[(c["domain"], c["part"])] = c
    out = sorted(merged.values(), key=lambda c: (c["domain"], CUT_ORDER.index(c["part"])))
    return blocks, out


def fit_corpus(cards: list, *, corpus_budget: int = CORPUS_BUDGET) -> tuple:
    rows = list(cards)
    cuts: list = []
    families: dict = {}
    for c in cards:
        if c.get("family"):
            families.setdefault(c["family"], []).append(c)
    for root, members in sorted(families.items(), key=lambda kv: (-len(kv[1]), kv[0])):
        if size(rows) <= corpus_budget:
            break
        names = [m["domain"] for m in members]
        rows = [r for r in rows if r.get("domain") not in names]
        rows.append({"family": root, "collapsed": True, "domains": names,
                     "documents": sum((m.get("unit") or {}).get("documents", 0) for m in members),
                     "entities": sum(m.get("entities", 0) for m in members),
                     "stores": sorted({s for m in members for s in m.get("stores", [])})})
        cuts.append({"part": "cards", "domain": root, "shown": 0, "total": len(members),
                     "rest": f"artmind query orient --domain {root}"})
    rows.sort(key=lambda r: r.get("domain") or r.get("family"))
    return rows, cuts
```

```python
"""`artmind query orient`: a layered, question-free description of the corpus (spec 2026-11-09).

`orient()` is peel 1 (corpus + one card per domain); `orient(domains)` is peel 2 (one block per
domain and its dotted children). Facts only: no question input, no route, no LLM call.
"""
from __future__ import annotations

from loguru import logger

from artmind import domain_config
from artmind.orient import budget, card, domain, schema_facts

PARTS = ("classes", "shapes", "types", "documents", "versions", "stores", "time", "assets", "health")
NEXT_PEEL = "artmind query orient --domain <domain> --compact"


def _known_domains() -> list:
    """Domains with a schema here, a structured table or graph data. `general` (always in the schema
    list) only when it holds graph data."""
    from artmind import domain_guard

    names = set(domain_guard._schema_domains())
    try:
        names |= domain_guard._table_domains()
    except Exception as exc:
        logger.debug("orient: no table domains: {}", exc)
    try:
        graph = domain_guard._graph_domains()
    except Exception as exc:
        logger.debug("orient: no graph domains: {}", exc)
        graph = set()
    names |= graph
    if "general" not in graph:
        names.discard("general")
    return sorted(names)


def _catalogues(domains):
    from artmind.catalogue import cache

    cats, _ = cache.get_detailed(domains, PARTS)
    return cats


def _facts(d: str, warnings: list):
    try:
        return schema_facts.read(d)
    except schema_facts.SchemaFactsError as exc:
        warnings.append(str(exc))
        return None


def _narrator(d: str, warnings: list):
    try:
        return domain_config.narrator(d)
    except domain_config.DomainConfigError as exc:
        warnings.append(f"{d}: voice unknown: {exc}")
        return None


def _offline_card(d: str, facts, narrator, family) -> dict:
    c = {"domain": d, "family": family[0], "siblings": family[1]}
    if facts and facts.get("purpose"):
        c["purpose"] = facts["purpose"]
    c["voice"] = None if narrator is None else {"narrator": narrator["name"], "entity_class": narrator["entity_class"],
                                                "first_person": True}
    if facts:
        c["time"] = {"rule": facts.get("time_rule") or {}}
    return c


def corpus() -> dict:
    warnings: list = []
    names = _known_domains()
    tree = card.family_tree(names)
    try:
        cats = _catalogues(names)
    except Exception as exc:
        from artmind.cli_conventions import store_failure

        failure = store_failure(exc)
        if failure is None:
            raise  # a bug, not an unreachable store
        warnings.append(f"graph unreachable at {failure[1]}: cards carry schema facts only")
        cats = None
    cards = []
    for d in names:
        facts, narrator, family = _facts(d, warnings), _narrator(d, warnings), card.family_of(d, tree)
        if cats is None:
            cards.append(_offline_card(d, facts, narrator, family))
        else:
            cards.append(card.build_card(cats[d], facts, narrator, family,
                                         children=len(tree.get(d, [])), warnings=warnings))
    gens = [c.fingerprint[0] for c in (cats or {}).values() if c.fingerprint]
    built = max((c.built_at for c in (cats or {}).values()), default=None)
    rows, cuts = budget.fit_corpus(cards)
    return {"warnings": warnings, "next": NEXT_PEEL, "peel": 1,
            "corpus": card.corpus_block(cards, tree, generation=sum(gens), built_at=built),
            "domains": rows, "cuts": cuts}


def _expand(domains) -> list:
    """A family root opens its children (catalogue parts roll children up, so a root block would
    repeat them); a leaf opens itself."""
    known = _known_domains()
    out = []
    for d in domains:
        out += [k for k in known if k.startswith(d + ".")] or [d]
    return list(dict.fromkeys(out))


def domains(requested) -> dict:
    warnings: list = []
    names = _expand(requested)
    tree = card.family_tree(_known_domains())
    cats = _catalogues(names)
    blocks = []
    for d in names:
        facts, narrator = _facts(d, warnings), _narrator(d, warnings)
        c = card.build_card(cats[d], facts, narrator, card.family_of(d, tree), warnings=warnings)
        blocks.append(domain.build_block(cats[d], facts, card=c, warnings=warnings))
    blocks, cuts = budget.fit_domains(blocks)
    return {"warnings": warnings, "next": None, "peel": 2, "domains": blocks, "cuts": cuts}
```
