# artmind-query, classic text (archived 2026-11-11)

The `artmind-query` skill as it stood before the orient variant replaced it (work plan item C, spec
`docs/superpowers/specs/2026-11-08-classic-baseline-and-skill-simplification-design.md`). Every baseline run in
study note 22 (banking A/D/G, brain01 A/D/G1/G2) answered with this text. Kept for reference and for rerunning a
baseline; it is not shipped or seeded. The orient text that replaced it passed every floor in runs L, M and N
(`docs/query-routing-study/22-p2-1-orient.md`).

To rerun a baseline with it, copy this folder (plus the shared `references/` of `artmind/skills/artmind-query/`)
into a vault's `.claude/skills/artmind-query-classic/` and start the benchmark with contract `classic`.
